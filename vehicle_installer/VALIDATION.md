# 实车安装器验证范围

日期：2026-11-26。当前版本：0.2.0。以下测试均未连接真实车辆或改写正在运行的模拟器。

## 安装与恢复

25 项自动测试覆盖：

- 初次安装、已有插件升级、恢复旧插件、初次安装后恢复为没有插件。
- 保留 `iap.off`、已有解码设置和测试配对数据，首次安装默认硬件解码。
- 写入暂存文件失败时原插件不变；激活过程 4 次目录改名分别注入失败，检查两套旧目录均恢复。
- 激活后回读不一致时回滚；远端完成激活但 SSH 断开时保持“状态未知”和恢复锁，重连后从相应备份恢复。
- 未完成远端脚本仍在运行时拒绝恢复；他人事务锁、本地双开、空间不足和符号链接阻止重复写入。
- 恢复过程再次断线时继续使用最初完整备份，恢复事务接管期间不释放远端安装锁。
- 校验失败或属于另一台车机的备份不能恢复。
- 只检查连接不创建远端文件；Linux、ARM、SH4、QNX 6.3.2、非 root 或缺少认证接口被拒绝。
- SSH 身份改变被拒绝；ZIP 变更、目标越界和路径穿越被拒绝。
- HSFZ 请求报文与 ACK、Pending、接受、拒绝、截断及异常长度回应。
- 真实 Paramiko 客户端连接本机临时 SSH 服务，验证密码认证、SSH 身份固定、512 KiB 二进制传输和回读、输出上限及错误命令处理；不启用 SFTP。

事务测试在临时目录运行实际 POSIX shell 激活/回滚脚本；SSH 传输层使用隔离文件系统替身，身份检查与网关回应单独模拟。Windows 使用 Git Bash 执行隔离脚本，部分 POSIX 权限和链接测试按平台跳过。这些测试不能证明 QNX 实机 shell、SSH、文件系统或原车服务行为一致。

## 应用打包

- macOS Apple Silicon：本机 Tk GUI 自检、PyInstaller 构建、临时签名验证及打包后隐藏 GUI 自检。
- Windows x64：GitHub Actions 原生构建，运行测试，再执行 `.exe --self-test` 并验证输出报告。
- 官方固定发布包的全包 SHA-256 和 27 项清单独立核验。应用内带 HTTPS 根证书，下载不依赖开发机的 Homebrew 路径。

构建日志和 Windows 自检结果在 GitHub Actions / 发布附件中。源码和 GUI 自检结果不代表实车安装成功。

## 尚未验证

- 尚未在实车执行 ENET 安装、ZGW 重启、断线恢复、原厂 HMI 插件加载或 iPhone CarPlay 连接。
- 没有宣称支持所有原始 NBT 硬件版本、全部固件或无线 CarPlay。
- 两个目录的切换不是文件系统级单次原子操作；命令失败有恢复陷阱，但断电、文件系统故障和 SSH 丢失仍可能需要人工处理。
- 没有 Apple Developer ID 公证和 Windows 发行证书；跨版本 macOS、Intel Mac、Windows ARM、杀毒软件兼容性未验证。
